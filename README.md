# Automated-Optical-Test-Platform
**Problem**
Evaluating optical output quality (brightness, contrast) required consistent, repeatable measurement conditions across many units — manual setup and measurement made it difficult to test units at scale with consistent accuracy and throughput.

**My Role**
Designed and developed the application controlling the stepper-motor-driven conveyor belt to automatically position each unit for testing
Integrated spectrometer readings captured from the projection wall during each test cycle
Built logic to plot and evaluate spectrometer readings (brightness, contrast, voltage) against defined pass/fail criteria
Automated the full test sequence from unit positioning through measurement and result classification

**Tools & Technologies**
LabVIEW (application development + GUI)
Stepper motor control (conveyor automation)
Spectrometer integration and data acquisition
Pass/fail criteria evaluation logic

**Outcome**
Enabled consistent, automated optical testing across units without manual positioning or measurement
Delivered repeatable brightness/contrast/voltage evaluation against defined quality criteria
Improved test throughput and consistency compared to manual measurement approaches
